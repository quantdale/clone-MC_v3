# add-voxel-game

Browser-based Three.js voxel sandbox game

## Spec structure

Each capability spec under `specs/<capability>/spec.md` includes a `## Contract` section (Purpose / Scope / Functional requirements / Non-functional requirements / Inputs and outputs / Core data structures / Dependencies / Error and edge-case behavior / Performance expectations / Acceptance criteria / Verification method) per the project's mandated structure, followed by the original scenario-based `## ADDED Requirements` blocks (Requirement + Scenario), which are retained intact below the contract.
